# PRAE hardware and ports

PRAE has its native 8 by 5 keyboard, software RS-232, cassette input/output, speaker and 256 by 256 monochrome display. The CPU-visible archived ROMs account for the crossed D3/D4 EPROM data lines.

| Address | Interface |
| --- | --- |
| 0000-3FFF | BASIC ROM 3.6 or 3.5 |
| 4000-FFFF | 48 KiB RAM |
| E000-FFFF | Linear monochrome bitmap |
| xx80 input | D0-4 keyboard, D6 serial RX, D7 cassette |
| xx80 output | D6 serial TX, D7 cassette / speaker |

CPU: 2.5 MHz. Keyboard lines A8-A15 are active low. Serial timing is generated by the original firmware; the default is 300 baud, 7 data bits and 2 stop bits. Dedicated PC punctuation keys produce the original SHIFT combinations. The manual discusses floppy support as a future version and supplies no PRAE-M floppy-controller circuit or boot software.

The raster uses nominal functional timings; the FPGA clock enables preserve the CPU and peripheral rates. Serial signals are logical-level interfaces exposed by MiSTer; the core does not emulate analog voltage drivers.
